# Submission checklist

## Before uploading

- [ ] Replace `[Your Name]` in `docs/Titanic_Decision_Tree_Project_Report.docx` and `docs/PROJECT_REPORT.md`.
- [ ] Download `train.csv` from the official Kaggle data page and rerun the model locally.
- [ ] Confirm the script completes and `PYTHONPATH=src pytest -q` passes.
- [ ] Read the README and be ready to explain the train/validation split, missing-value imputation, one-hot encoding, accuracy, confusion matrix, and feature importance.

## Publish the code on GitHub

1. Sign in to GitHub and choose **New repository**.
2. Give it a name such as `titanic-decision-tree`; set it to **Public** if the judges require a public repository.
3. Create the repository without adding a second README (this project already has one).
4. In the new repository, choose **Add file → Upload files** and upload the contents of this project folder (not the ZIP as a single file).
5. Commit the upload. Open the repository in a private/logged-out window to confirm that the files are publicly visible.
6. Copy the repository URL for your submission.

## Create the public Google Docs document

1. Upload `docs/Titanic_Decision_Tree_Project_Report.docx` to Google Drive.
2. Open the uploaded file with Google Docs and check the formatting and figures.
3. Replace `[Your Name]` and any details required by your course.
4. Select **Share → General access → Anyone with the link → Viewer** if permitted by your institution.
5. Copy the Google Docs link and test it in a private/logged-out browser window.

## Final submission

- [ ] Public GitHub repository link
- [ ] Public Google Docs report link
- [ ] Code runs using the README instructions
- [ ] Report screenshots/charts match the output generated by the code
