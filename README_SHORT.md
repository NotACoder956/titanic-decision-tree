# Titanic Survival Prediction

A small, interpretable machine-learning project using Pandas and scikit-learn. It predicts the `Survived` label from `Pclass`, `Sex`, `Age`, and `Fare`, handles missing values in a pipeline, evaluates on a stratified holdout set, and saves feature-importance, confusion-matrix, and tree visualisations.

Start here: [README.md](README.md). Dataset download instructions: [data/README.md](data/README.md).
